AIMA Ch02：理性代理、PEAS 與代理架構階梯AIMA Ch02: Rational Agents, PEAS, and the Agent Architecture Ladder

AI 的統一框架是「代理」：感測環境、依績效量度選行動；PEAS 刻劃任務，七維環境決定選哪種架構——從簡單反射到學習型五級。

The unifying AI framework is 'agent': perceive the environment, select actions to maximise a performance measure. PEAS describes the task; seven environment dimensions determine which architecture—simple reflex through learning agent—is appropriate.

是什麼 · What it is

代理（Agent） = 透過感測器感知環境、透過致動器行動的系統（AIMA 4th Ed. §2.1）。

理性代理（Rational Agent, §2.2）：對每一個可能的感知序列，選擇能最大化績效量度（performance measure）期望值的行動——以至今的感知序列及代理人內建的知識為依據。

理性 ≠ 全知（omniscience）。理性 = 在現有資訊與計算資源下做期望最好的選擇（bounded rationality）。若收集更多資訊能提升績效，理性代理應去收集——即學習。

An agent perceives its environment via sensors and acts via actuators (§2.1). A rational agent (§2.2) selects, for each possible percept sequence, the action that maximises its performance measure in expectation given available percepts and built-in knowledge. Rationality ≠ omniscience: a rational agent acts on the best available expected outcome and should gather more information when doing so improves performance.

出處 Source：Russell & Norvig, Artificial Intelligence: A Modern Approach, 4th Ed., §2.1–2.2（pp. 55–60），作者改寫重述。Paraphrased from R&N AIMA 4th Ed. §2.1–2.2.

PEAS 框架（§2.3）——設計代理前先回答四個問題：

要素說明自駕計程車範例
Performance績效量度：怎樣算成功安全、合法、快速、乘客舒適、利潤
Environment環境：代理人所在世界道路、其他車輛/行人、天氣、號誌
Actuators致動器：可執行的動作方向盤、油門、煞車、喇叭、顯示器
Sensors感測器：接收環境資訊的管道相機、光達、GPS、速度計、里程計

PEAS (§2.3): before designing an agent, specify Performance measure, Environment, Actuators, and Sensors. Example — self-driving taxi: P = safety/legality/speed/comfort/profit; E = roads/vehicles/pedestrians/traffic; A = steering/throttle/brakes/horn; S = cameras/lidar/GPS/speedometer.

出處 Source：AIMA 4th Ed. §2.3（pp. 60–65），作者改寫重述。Paraphrased from R&N §2.3.

任務環境七維度（§2.3）——決定要選哪種代理架構：

維度選項越難的方向範例（易→難）
可觀察性完全 / 部分部分 → 需內部狀態完全：西洋棋（棋盤全可見）／部分：撲克牌、自駕車（有感測盲區）
代理人數單一 / 多多 → 需博弈推理單一：掃地機器人／多：西洋棋（對手）、交通（其他車輛）
確定性確定 / 隨機（/ 策略性）隨機 → 需機率推論確定：西洋棋（規則固定）／隨機：自駕車（路況不可預測）／策略性：雙陸棋
情節性情節 / 序列序列 → 需規劃情節：垃圾郵件分類（每封獨立）／序列：西洋棋、自駕車（每步影響後局）
動態性靜態 / 動態（/ 半動態）動態 → 決策時環境在變靜態：填字遊戲／半動態：西洋棋計時賽（時鐘在跑）／動態：自駕車
離散性離散 / 連續連續 → 需連續狀態方法離散：西洋棋（有限棋步）／連續：自駕車（速度/方向）、機器手臂
知識已知 / 未知未知 → 需探索/學習已知：西洋棋規則／未知：探索新環境、第一次玩新桌遊

自駕車 = 部分可觀察、多代理、隨機、序列、動態、連續、未知 → 最難象限，需機率推論 + 規劃 + 強化學習。

The seven environment dimensions (§2.3) determine which algorithm/architecture fits: partially observable → need internal state; multi-agent → game-theoretic reasoning; stochastic → probability; sequential → planning; dynamic → decisions under time pressure; continuous → continuous-state methods; unknown → exploration/learning. Self-driving cars hit all the hard ends simultaneously.

出處 Source：AIMA 4th Ed. §2.3（pp. 60–65），作者改寫重述。Paraphrased from R&N §2.3.

代理架構五級階梯（§2.4）：

架構核心適用環境
簡單反射（Simple Reflex）condition-action 規則，只看當前感知完全可觀察 + 無記憶需求
基於模型反射（Model-based Reflex）維護內部世界模型補部分可觀察部分可觀察
基於目標（Goal-based）目標 + 搜尋/規劃決定行動序列需達成明確目標
基於效用（Utility-based）效用函數取捨多目標/不確定性多目標衝突或隨機結果
學習型（Learning）以上任一架構 + 學習元件，從經驗改進未知/非穩態環境
學習型不是獨立類別，而是任何架構 + 學習元件的疊加。

The five-level architecture ladder (§2.4): Simple Reflex (condition-action rules, no memory); Model-based Reflex (internal world model for partial observability); Goal-based (search/planning to reach goals); Utility-based (utility function to trade off competing objectives); Learning agent (any architecture + learning component that improves with experience). Learning agents are not a separate category — they are an overlay on any of the above.

出處 Source：AIMA 4th Ed. §2.4（pp. 66–75），作者改寫重述。Paraphrased from R&N §2.4.

為什麼重要 · Why it matters

AIMA Ch02 是整本書的全景索引：後面每一章（搜尋、邏輯、機率、規劃、學習、強化學習）都是「讓代理在某種環境維度組合下理性行動」的工具。

考試策略：遇到「描述某系統的代理設計」→先填 PEAS → 判定七維度 → 由難易選架構。部分可觀察 + 隨機 → 信念狀態 / MDP；多代理 → 對抗搜尋/機制設計。

代理設計範例（PREP 論述結構）

Point（論點）：「外送機器人」在最難維度組合下，需要學習型 + 效用型架構。

Reason（理由）：環境維度直接決定演算法工具——部分可觀察逼出內部模型，隨機逼出機率推論，序列性逼出規劃，多代理逼出博弈推理；一個環境若同時觸發多個「難」軸，架構就必須疊加對應能力。

Example（例證）：

| PEAS 要素 | 外送機器人 |
|---|---|
| Performance | 準時送達、零碰撞、最短路徑、低電耗 |
| Environment | 街道、行人、車輛、紅綠燈、天候 |
| Actuators | 馬達、轉向、剎車、蜂鳴器 |
| Sensors | GPS、相機、距離感測、里程計 |

七維度判定：部分可觀察（無法看到所有行人意圖）、多代理（其他車輛/行人）、隨機（天候/行人路徑不可預期）、序列（路線決策影響後續）、動態（即時交通持續變化）、連續（位置/速度）、未知（首次跑的新路段）→ 7/7 全命中難側。

架構選型：簡單反射不夠（部分可觀察）→ 需基於模型（維護世界狀態）；多目標衝突（速度 vs 安全）→ 需效用函數；新環境動態未知 → 需學習元件。最終：學習型效用代理 + 信念狀態 + 規劃。

Point（結論）：PEAS → 七維 → 架構這條流程，讓申論題有系統性骨幹，不必靠直覺列舉；每個維度都對應一個「不夠就升架構」的充分理由。

LLM agent 的現代對應：感知 = prompt/工具回傳，行動 = 工具呼叫，記憶 = context/向量庫，學習 = fine-tuning/RLHF。ReAct（推理+行動交錯）正是本章「基於目標 + 學習型」在 LLM 時代的體現。

Exam strategy for "describe the agent design of a system" — use the P-R-E-P structure: Point: A food-delivery robot operating in a fully hard environment requires a learning + utility-based architecture. Reason: Environment dimensions directly map to algorithm needs — partial observability demands an internal model; stochasticity demands probabilistic reasoning; sequential decisions demand planning; multi-agent settings demand game-theoretic reasoning. When multiple "hard" dimensions fire simultaneously, the architecture must stack corresponding capabilities. Example — Food Delivery Robot: P = on-time/collision-free/shortest path/low battery; E = streets/pedestrians/vehicles/traffic lights/weather; A = motors/steering/brakes/horn; S = GPS/cameras/range sensors/odometer. All 7 dimensions hit the "hard" end: partially observable, multi-agent, stochastic, sequential, dynamic, continuous, unknown. Architecture chain: simple reflex insufficient → model-based (track world state) → utility (trade off speed vs safety) → learning (handle unknown routes). Result: learning + utility-based agent with belief state and planning. Point: The PEAS → dimensions → architecture pipeline gives exam answers a systematic skeleton rather than an ad-hoc list; each hard dimension is a justified reason to move one step up the architecture ladder.

進階延伸 · Advanced Topics (§2.5+)

多代理系統：多個代理共存，可分為合作型（共享目標，任務分配/協商）與競爭型（博弈，納許均衡）。環境維度「多代理」軸決定是否需要博弈推理（→第五章對抗搜尋）。

BDI 架構（Belief–Desire–Intention）：符號式審議代理，維護信念（世界模型）、慾望（目標集）、意圖（已承諾的計畫）三層結構，是知識型代理的經典框架。

包容架構（Brooks）：分層反應式行為，無中央知識模型；低層行為可「包容」（subsume）高層行為輸出，適合即時機器人。

有限理性（Bounded Rationality, Simon）：在計算/資訊受限下採用「足夠好（satisficing）」策略。理性 ≠ 全知——這是讓理性代理可工程化的關鍵假設，也是整本 AIMA 的前提。

LLM 作為代理（當代對應）：感知 = prompt/工具回傳，行動 = 工具呼叫，記憶 = context window/向量庫，學習 = fine-tuning/RLHF。ReAct（推理 + 行動交錯）正是本章「基於目標 + 學習型」在大型語言模型時代的體現。

Multi-agent systems: agents coexist cooperatively (shared goals, task allocation, negotiation) or competitively (game-theoretic reasoning, Nash equilibria). The multi-agent dimension triggers Chapter 5's adversarial search tools. BDI architecture: symbolic deliberative agents maintain beliefs (world model), desires (goal set), and intentions (committed plans). Subsumption architecture (Brooks): layered reactive behaviours with no central knowledge model — lower layers can subsume (override) higher-layer outputs; well-suited for real-time robotics. Bounded rationality (Simon): under limited computation/information, agents satisfice rather than optimise — this is what makes rational agents engineerable. LLMs as agents: perception = prompt/tool returns; action = tool calls; memory = context window/vector store; learning = fine-tuning/RLHF. ReAct (interleaved reasoning + acting) is the goal-based + learning architecture from this chapter instantiated in LLMs.

練習題解答 · Exercise Answers (aimacode/aima-exercises Ch.2)

以下為 官方練習題 精選題目的參考解答。

Ex.4 — 以下敘述各為真或假？（理性代理基礎觀念）

  • (a) 只感知部分狀態的代理無法完全理性。→ 假：理性 = 在已知感知下做期望最好的選擇；感知受限不妨礙理性，只是限制了可用資訊。反例：只感知溫度的恆溫器仍可理性。
  • (b) 存在環境使純反射代理無法理性行動。→ 真：若環境需要記住歷史（如吸塵器無位置感測器，需記住已清潔格），純反射代理因無內部狀態而反覆循環，無法達最佳績效。
  • (c) 存在環境使每個代理都是理性的。→ 真：若所有行動績效期望值相同（如全空地圖無任何任務），任何代理行為都不劣於其他代理，故每個都「理性」。
  • (d) 代理程式的輸入與代理函數的輸入相同。→ 假：代理函數接受完整感知序列（歷史）；代理程式只接受當前感知，內部狀態由程式自己維護。
  • (e) 在完全不可觀察的環境中每個代理都理性。→ 假：無感知代理無法做任何有依據的決策；若一代理固定選次優動作，另一代理固定選最優動作，後者期望績效更高，前者不理性。
  • (f) 完全理性的撲克代理永遠不輸。→ 假：理性最大化期望效用（長期平均），但每手牌有隨機性；即使策略最優，單局仍可能因牌面運氣輸牌。
  • (i) 純隨機選動作的代理在某確定性環境中理性。→ 真：若確定性環境中任何動作序列績效相同（平坦環境），隨機選擇不劣於任何固定策略，故可理性。

Ex.4 — True/False on rational agents: (a) False — rational means best action given available percepts; partial perception limits information, not rationality itself. (b) True — an environment requiring memory (e.g. vacuum world without location sensor) cannot be handled by a pure reflex agent that loops forever. (c) True — if all actions yield the same expected performance (completely flat environment), every agent is trivially rational. (d) False — agent function takes the complete percept history; agent program receives only the current percept and maintains internal state itself. (e) False — with zero perception an agent cannot distinguish states; a fixed suboptimal action sequence can be beaten by another agent. (f) False — rational maximises expected (long-run) utility; stochastic card deals mean even the best strategy loses individual hands. (i) True — if every action achieves identical performance in a deterministic environment, random selection is as good as any fixed policy.

Ex.5 — 為以下任務描述 PEAS 並判定七維度

範例一：踢足球

  • P：進球、防守、守規則、贏比賽。
  • E：足球場、球、隊友、對手、裁判。
  • A：腳（踢/傳/射）、身體（衝撞/佔位）、口語（溝通）。
  • S：視覺、本體感覺（位置/速度）、聽覺（哨音/呼叫）。

七維度：部分可觀察（遮擋/視角盲區）、多代理（22 名球員）、隨機（球路/身體接觸不可預期）、序列（每個動作影響後續戰術）、動態（場況持續改變）、連續（位置/速度）、已知（規則事先已知）。

範例二：在網路上購買二手 AI 書

  • P：以最低價取得目標書籍、節省時間。
  • E：網頁、電商平台、搜尋引擎、其他買家。
  • A：輸入關鍵字、點連結、填表單、付款。
  • S：網頁內容（文字/圖片）。

七維度：部分可觀察（無法同時看所有賣家庫存）、多代理（其他買家競爭）、隨機（庫存/價格隨時變化）、序列（搜尋→比價→下單有順序依賴）、動態（價格和庫存持續改變）、離散（書籍為可數物件）、未知（新網站/未知賣家）。

Ex.5 — PEAS + environment dimensions: Soccer: P = score goals / defend / win; E = field, ball, teammates, opponents, referee; A = legs/body, voice; S = vision, proprioception, hearing. Dimensions: partially observable, multi-agent, stochastic, sequential, dynamic, continuous, known (rules). Online used-book shopping: P = acquire book at lowest cost / save time; E = web pages, e-commerce sites, other buyers; A = type queries, click, fill forms, pay; S = web content. Dimensions: partially observable, multi-agent, stochastic, sequential, dynamic, discrete, unknown (new sites).

Ex.7 — 定義以下術語

  • Agent（代理人）：透過感測器感知環境、透過致動器行動的任何實體。
  • Agent function（代理函數）：從感知序列到行動的數學映射（抽象規格）。
  • Agent program（代理程式）：在機器上執行、實現代理函數的具體程式碼（只接收當前感知）。
  • Rationality（理性）：選擇在至今感知序列與先驗知識下、期望績效最大化的行動。
  • Autonomy（自主性）：依靠自身感知與學習（而非僅靠設計者的內建知識）行動的程度。
  • Reflex agent（反射代理）：純粹根據當前感知套用 condition-action 規則，無記憶/歷史。
  • Model-based agent（基於模型的代理）：維護內部世界狀態（模型），以應對部分可觀察環境。
  • Goal-based agent（基於目標的代理）：用目標 + 搜尋/規劃決定達成目標的行動序列。
  • Utility-based agent（基於效用的代理）：用效用函數在多目標/不確定結果間取捨，選期望效用最高的行動。
  • Learning agent（學習型代理）：以上任一架構加上學習元件，從經驗中改善未來績效。

Ex.7 — Definitions: Agent: any entity that perceives its environment via sensors and acts via actuators. Agent function: abstract mathematical mapping from percept sequences to actions. Agent program: concrete implementation running on hardware that receives only the current percept. Rationality: choosing the action that maximises expected performance given the current percept sequence and built-in knowledge. Autonomy: the degree to which an agent relies on its own percepts and learning rather than purely on the designer's prior knowledge. Reflex agent: acts solely on current percept via condition-action rules; no memory. Model-based agent: maintains an internal world state to cope with partial observability. Goal-based agent: uses goals plus search/planning to determine action sequences. Utility-based agent: uses a utility function to trade off competing objectives or uncertain outcomes, selecting the action with highest expected utility. Learning agent: any of the above architectures augmented with a learning component that improves performance through experience.

Ex.10（延伸）— 恆溫器是哪種代理架構？

恆溫器是簡單反射代理：感知當前溫度，套用固定規則（溫度 < 設定 − 3°→ 開暖氣；溫度 > 設定 + 3° → 關暖氣）。無需內部狀態（溫度完全可觀察）、無目標搜尋、無效用函數——condition-action 規則完全描述其行為。

Ex.10 — Thermostat architecture: A simple reflex agent. It senses the current temperature and applies fixed condition-action rules (temperature < setting − 3° → turn on furnace; temperature > setting + 3° → turn off furnace). No internal state is needed (temperature is fully observable), no search or planning is performed, and no utility function is used — a pure condition-action mapping.

視覺 SLAM 是反問題：相機把 3D 壓成 2D，你得從影像反推——indirect 比幾何、direct 比像素Visual SLAM Is an Inverse Problem: the Camera Squashes 3D into 2D, So You Reconstruct from Images — Indirect Compares Geometry, Direct Compares Pixels

相機就是一個已知的投影：K[R|t] 把 3D 世界壓成 2D 影像，過程中丟掉了深度。所以視覺 SLAM 是個反問題——從一堆 2D 觀測反推相機位姿與 3D 結構。兩幀之間怎麼對上有兩條路：indirect 先抽特徵點、最小化幾何重投影誤差；direct 直接比像素灰階、最小化光度誤差。選哪種誤差，就是又一次「選 loss＝選世界觀」。

A camera is a known projection: K[R|t] squashes the 3D world into a 2D image, throwing away depth. So visual SLAM is an inverse problem — reconstruct the camera pose and 3D structure from 2D observations. Matching two frames has two roads: indirect extracts feature points and minimizes geometric reprojection error; direct compares pixel intensities and minimizes photometric error. Which error you pick is, once again, "choosing a loss = choosing a worldview."

是什麼 · What it is

視覺 SLAM 跟 卡 45／46 的 SLAM是同一件事，只是「觀測」換成相機影像。關鍵先認清：相機是一個已知的投影 x ~ K[R|t]X——把 3D 世界點壓成 2D 像素，過程中深度被壓掉了。所以視覺 SLAM 本質是反問題：手上只有 2D 影像，要反推出相機位姿 [R|t] 與 3D 結構。

而「相鄰兩幀怎麼對上（估出相對位姿 T）」有兩條路，差別就在最小化哪一種誤差：

indirect（間接法）：先抽特徵點，最小化幾何重投影誤差 T = argmin Σ‖u' − Tp‖²——比的是「點投影到哪」。代表：ORB-SLAM。
direct（直接法）：不抽特徵，直接最小化光度誤差 T = argmin Σ‖I_k(u') − I_{k−1}(u)‖²——比的是「像素灰階對不對」。代表：LSD-SLAM、DSO。

用多少影像資訊也是個選擇：sparse（只用特徵點）／dense（全部像素）／semi-dense（重要的點）。

Visual SLAM is the same thing as the SLAM of cards 45/46, except the "observation" is now a camera image. First see the crux: a camera is a known projection x ~ K[R|t]X — it squashes 3D world points into 2D pixels, and depth gets flattened away. So visual SLAM is fundamentally an inverse problem: with only 2D images in hand, reconstruct the camera pose [R|t] and the 3D structure. And "how to match two adjacent frames (estimate the relative pose T)" has two roads, differing in which error you minimize: indirect extracts feature points and minimizes the geometric reprojection error T=argmin Σ‖u'−Tp‖² — comparing "where points project to" (e.g. ORB-SLAM); direct skips features and minimizes the photometric error T=argmin Σ‖I_k(u')−I_{k−1}(u)‖² — comparing "do the pixel intensities agree" (e.g. LSD-SLAM, DSO). How much of the image you use is also a choice: sparse (feature points only) / dense (all pixels) / semi-dense (the important points).

為什麼重要 · Why it matters

該帶走的第一個洞見：indirect vs direct，就是「對哪個殘差做最小平方」的選擇——又一次 選哪個 loss 就選了世界觀：比幾何點位置，還是比像素亮度，決定了這個系統對什麼敏感、在什麼情況下會壞（弱紋理、光照變化各有死穴）。它跟 卡 46 的最小平方是同一招，只是誤差項換成了重投影或光度。

第二個、也是最該帶走的：觀測永遠是對真實的有損投影，SLAM 做的是「反推一個最能解釋所有觀測的 3D 解釋」。這在 bundle adjustment 裡最清楚——當 3D 結構也未知時，同時優化所有相機位姿與所有 3D 點，讓它們投影回各張影像的重投影誤差總和最小。這正是 graph 最佳化的推廣：不是挑一張影像信，而是找一組「對全部觀測最一致」的結構與位姿。（若 3D 結構已知，問題退化成 PnP：給 n 個 3D-2D 對應就能解相機位姿，Marker AR 就是這樣把虛擬物件貼到現實。）

把整門課縫起來：相機把 3D 壓成 2D ＝一次有損的「觀測」，視覺 SLAM 用最小化重投影/光度誤差把 3D 反推回來——這還是 predict-correct、也是整站「觀測是有損的，要靠對所有證據最一致的估計把真實重建回來」的母題，只是搬到了相機幾何上。

一句話帶走 · Takeaway

相機用 K[R|t] 把 3D 壓成 2D、丟掉深度，所以視覺 SLAM 是從影像反推位姿與結構的反問題。兩幀對上有兩條路：indirect 最小化幾何重投影誤差、direct 最小化光度誤差——選哪個誤差就是選世界觀。Bundle adjustment 聯合優化相機與 3D 點，是 graph 最佳化的推廣，也還是「觀測有損、反推最一致真實」的老母題。

A camera's K[R|t] squashes 3D into 2D and discards depth, so visual SLAM is the inverse problem of reconstructing pose and structure from images. Matching frames has two roads: indirect minimizes geometric reprojection error, direct minimizes photometric error — and which error you pick is choosing a worldview. Bundle adjustment jointly optimizes cameras and 3D points, generalizing graph optimization, and is still the old theme of "observation is lossy; reconstruct the most consistent reality."

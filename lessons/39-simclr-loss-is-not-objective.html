SimCLR 實作：loss 下降 ≠ 學得好——對比學習逼你用下游任務驗證表徵SimCLR in Practice: Falling Loss ≠ Good Representations — Contrastive Learning Forces You to Verify via a Downstream Task

SimCLR 用「在 2N 張圖裡找出自己的擴增雙胞胎」當作一個分類問題，NT-Xent 其實就是對比版的 cross-entropy。但最該帶走的實作教訓是：訓練 loss 一路下降，不代表表徵變好——因為 loss≠objective。你得用 linear probing 或 kNN monitor 這種獨立的下游任務去驗證。這正是「不自評、要外部驗證」的動手版。

SimCLR treats "find your augmented twin among 2N images" as a classification problem, and NT-Xent is really contrastive cross-entropy. But the key implementation lesson: a steadily falling training loss does NOT mean the representation improved — because loss ≠ objective. You must verify with an independent downstream task like linear probing or a kNN monitor. This is the hands-on version of "don't grade yourself; verify externally."

是什麼 · What it is

這張是 「一切都在學一個嵌入」的動手版——把自監督對比學習真的跑起來（SimCLR，Chen et al. 2020, arXiv:2002.05709）。流程：一個 backbone（如 resnet-18）＋一個 projector head（兩層 MLP）；一批 N 張圖，每張做兩種隨機擴增（crop／flip／color jitter／grayscale＋normalize），於是有效批量變 2N。

核心是 NT-Xent loss，它其實是個很乾淨的分類問題：對某張圖 x，另外有 2N−1 張；把所有輸出向量正規化、兩兩算 cosine 相似度，除以一個 temperature 再取 softmax——x 的 loss ＝它「真正雙胞胎」那一項的負 log。這等價於把「在 2N−1 張裡找出 x 的配對」當成分類的 cross-entropy（呼應 選哪個 loss 就選了世界觀）。訓練完丟掉 projector，要的表徵是 backbone 的輸出。batch 越大、負樣本越多，學得越有效。

This is the hands-on version of "everything is learning an embedding" — actually running self-supervised contrastive learning (SimCLR, Chen et al. 2020, arXiv:2002.05709). The setup: a backbone (e.g., resnet-18) plus a projector head (a two-layer MLP); for a batch of N images, make two random augmentations each (crop / flip / color jitter / grayscale + normalize), so the effective batch is 2N. The core is NT-Xent loss, which is really a clean classification problem: for an image x there are 2N−1 others; normalize all output vectors, compute pairwise cosine similarity, divide by a temperature, take softmax — x's loss is the negative log of the term for its true twin. That's exactly the cross-entropy of "find x's mate among the 2N−1" (echoing choosing a loss is choosing a worldview). After training you discard the projector; the representation you want is the backbone output. Bigger batch = more negatives = more effective learning.

為什麼重要 · Why it matters

這張卡最該帶走的，是一個會反直覺、卻直通我研究紀律的實作教訓：訓練 loss 一路下降，不代表表徵變好——因為 loss ≠ objective。NT-Xent 降低，只說明「配對任務」在這批資料上越做越順，但你真正要的是「一個對下游任務有用的表徵」，兩者不是同一件事。所以 SimCLR 的評估必須靠獨立的下游任務：

linear probing：凍結 encoder、只在上面訓一個線性分類層，看準確率——它當「表徵品質」的量尺。
kNN monitor：訓練中每隔幾個 epoch，用當前表徵對測試集做 k-近鄰分類。因為不能只看 loss 曲線，用這個才看得到表徵實際在變好。

這就是 「不自評、要外部驗證」的動手版：優化的那個訊號（loss）不是你真正要的目標，所以不能拿它給自己打分，得換一個獨立量尺來驗。它跟 遊戲 AI 那條「估計器的可信度就是天花板」、RAG 的 faithfulness 閘門是同一條線——你拿來優化的代理指標，和你真正在乎的品質，中間永遠要插一道獨立驗證。

兩個延伸實作點也接得上本站：①temperature 控制對比分布的「銳利度」——太高（如 5）或太低（如 0.1）都會改變學習曲線，是另一個要調的旋鈕（精神上近 探索 vs 利用）。②為什麼 batch size 在 SimCLR 比一般監督式更關鍵？因為 batch 就是「負樣本池」——池子越大，「找出雙胞胎」這題越難、學到的嵌入越好。這也解釋了我為什麼在意嵌入模型的訓練規模：換嵌入＝換了「相似」的定義，而對比學習正是「相似」被訓練出來的過程。

一句話帶走 · Takeaway

SimCLR 把「找出自己的擴增雙胞胎」當分類，NT-Xent 就是對比版 cross-entropy。但訓練 loss 下降不代表表徵變好——loss≠objective，要用 linear probing／kNN monitor 這種獨立下游任務來驗。這正是「不自評、要外部驗證」的動手版，也是嵌入品質的真正量尺。

SimCLR frames "find your augmented twin" as classification, and NT-Xent is contrastive cross-entropy. But a falling training loss doesn't mean the representation improved — loss ≠ objective, so verify with an independent downstream task like linear probing or a kNN monitor. This is the hands-on form of "don't grade yourself; verify externally," and the real yardstick of embedding quality.

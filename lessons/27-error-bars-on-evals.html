Eval 分數要有誤差棒：「10/10 通過」的真實失效率上界可能是 30%——因為 0 失效 ≠ 0% 失效Put Error Bars on Eval Scores: "10/10 Passed" Allows a True Failure Rate up to ~30% — Because Zero Failures ≠ a Zero Failure Rate

一個沒有誤差棒的 eval 分數不是結果，是幻覺。評估是實驗：你的題目是一個樣本，裸的「80% 通過」沒有不確定區間等於沒說。最反直覺的一條是「三的法則」：某事在 n 次試驗中一次都沒出，它真實發生率的 95% 上界約是 3/n——所以 卡 26 的「10/10 通過」容得下高達 ~30% 的真實失效率。比較兩個模型也一樣：「A 贏 B 兩個百分點」可能整個藏在重疊的信賴區間裡。

An eval score with no error bar isn't a result — it's a hallucination. Evaluations are experiments: your questions are a sample, and a bare "80% pass" with no interval says nothing. The most counter-intuitive piece is the rule of three: if something occurs zero times in n trials, the 95% upper bound on its true rate is about 3/n — so card 26's "10/10 passed" is consistent with a true failure rate up to ~30%. Same for comparing models: "A beat B by 2%" can hide entirely inside overlapping confidence intervals.

是什麼 · What it is

Week 10 自學模組的三篇閱讀，講的是同一件事：評估的統計學。

  • Miller（2024）「給 eval 加誤差棒」：核心一句話是「評估就是實驗」。一個準確率是從有限題目樣本估出來的 → 要報信賴區間/標準誤，不是裸數字。三個關鍵：①題目獨立性——天真的誤差棒假設每題獨立；但題目成群（clustering，多題共用同一段落/文件）會打破獨立性，讓真實標準誤更大、裸數字過度自信。②配對 vs 非配對——比較兩模型時，讓兩者跑同一組題目（配對、看每題差異）會抵銷「題目難易」的雜訊 → 變異更小、同樣題數更有檢定力。③檢定力分析——動手前先算：要偵測某個大小的差異，需要多少題。
  • Anthropic（2026）「拆解 agent evals」：一個 eval 的結構＝任務（輸入＋成功標準）→ 試跑 → grader（評一個面向）→ transcript → 最終狀態；多個相關任務組成 suite（agent 更難，錯誤會跨回合累積）。兩種 eval：能力（capability）評估該從低分起步（一座要爬的山），回歸（regression）評估該貼近 100%（抓退步）；能力評估爬高了就「畢業」進回歸套件。非決定性 → 用 pass@k（k 次至少成功 1 次，一個好答案就夠）或 pass^k（k 次全成功，要一致性，面向客戶時用）：每次 75% 的話，pass^3 ≈ 0.75³ ≈ 42%。
  • 三的法則（rule of three，標準統計；Phillips 2005 指定）：某事件在 n 次獨立試驗中觀察到零次，其真實發生率的 95% 上界 ≈ 3/n。

Week 10's self-paced readings are all about the statistics of evaluation. Miller (2024): "evaluations are experiments" — an accuracy is estimated from a finite sample of questions, so report a confidence interval, not a bare number; question clustering (several questions sharing one passage) breaks the independence assumption and inflates the true standard error; comparing two models with paired questions (same items, per-question differences) cancels question-difficulty noise and gives more power than unpaired; power analysis tells you how many questions you need up front. Anthropic (2026): capability evals should start low (a hill to climb) while regression evals sit near 100% (catch backsliding); handle non-determinism with pass@k (≥1 of k succeeds) vs pass^k (all k succeed — e.g. 0.75³ ≈ 42%). Rule of three (standard statistics): zero events in n trials → 95% upper bound ≈ 3/n.

為什麼重要 · Why it matters

  • 「零失效」不等於「零失效率」。三的法則給了 卡 26「十個案例分不開訊號與雜訊」一個公式：0/10 通過 → 真實失效率上界 ~30%；0/30 → ~10%；0/100 → ~3%。所以「今天全過」遠不足以上線——你的證據只把失效率壓到一個區間，沒壓到零。（這也正是把 pilot 從 n=2 擴到 n=30 的統計理由：樣本越大，誤差棒越窄。）
  • 比較要配對，差異要看區間。「模型 A 贏 B 兩個百分點」如果沒用配對題目、題數又不夠，很可能整個落在重疊的信賴區間裡——那不是證據，是雜訊。頭條數字沒有誤差棒、沒有配對，不能當結論。
  • pass@k vs pass^k 看用途。探索時一個好答案就夠（pass@k）；面向客戶要每次都對（pass^k），而 pass^k 比直覺難得多（每次 75% → 連三次全對只剩 ~42%）。這呼應 卡 21 的隨機性與 卡 24 的量尺紀律。
  • 當心飽和（saturation）。當模型把你的 eval 全做對，它就量不出進步了（只能抓退步）；更騙人的是接近飽和時，巨大的能力提升只顯示成分數的微小跳動（Anthropic 舉 SWE-bench Verified ~30% → >80%）。解法：讀 transcript（是評分不公還是題目模糊？）、加更難的題、把飽和的 eval 移進回歸套件、持續拉高訊噪比。

一句話帶走 · Takeaway

沒有誤差棒的 eval 分數不是結果：評估是實驗，裸的「80% 通過」沒有區間等於沒說。記住三的法則——0 失效於 n 次試驗，真實失效率上界約 3/n（所以 10/10 容得下 ~30% 失效）；比較模型要用配對題目、看區間有沒有重疊；面向客戶看 pass^k 不是 pass@k；eval 一旦飽和就只剩抓退步、量不出進步。題數是第一等的設計決定。

An eval score without an error bar isn't a result: evaluations are experiments, and a bare "80% pass" with no interval says nothing. Remember the rule of three — zero failures in n trials bounds the true rate at about 3/n (so 10/10 allows ~30% failure); compare models with paired questions and check whether intervals overlap; for customer-facing work read pass^k not pass@k; and once an eval saturates it only catches regressions, not gains. Sample size is a first-class design decision.
